How to publish your reports site on GitHub Pages

Result: your HTML reports open in the browser via a link (e.g. https://YOUR-USERNAME.github.io/reports/greek-house/), and each partner only gets their own folder.

Step 0. Create a GitHub account (one-time)

  1. Go to github.com → Sign up.
  2. Create an account (email, username, password). Your username becomes the site address (https://USERNAME.github.io/...).
  3. Confirm your email.

How to upload reports with Cursor AI

The AI will create the repository, upload the files, enable GitHub Pages, and give you the ready links.

1. Create a token (Personal Access Token)

  1. Open github.com/settings/tokens/new (this is Tokens → classic).
  2. Note: cursor-upload.
  3. Expiration: e.g. 30 days.
  4. Scopes: check every box (not only repo).
  5. Generate token → copy it (it starts with ghp_...).
⚠️ The token is a secret. Do not send it to anyone and do not save it in files. After you are done, you can revoke it at github.com/settings/tokens.

2. Give the task to the AI in Cursor

Write something like this:

“Here is my token ghp_.... Create a public repository reports, put these HTML files into folders greek-house/, salateira/, etc., enable GitHub Pages, and give me a link to each folder.”

The AI will do the rest and return the ready links.

Privacy — what you need to know

  • The site is public: anyone with the link can open it. There is no login or password.
  • Partners will not see each other if you:
    • Do NOT create a homepage that lists every partner (the root /reports/ then returns 404);
    • Give each partner a link to their folder only.
  • Protection relies on the links being hard to guess. For commercial data, this is security through obscurity.
  • Need real password protection? Use Netlify (free) instead of GitHub Pages — you can put a password on the site.

    How to do it (free, via a _headers file):

    1. Sign up at app.netlify.com/signup and connect your GitHub repository (Add new site → Import an existing project).
    2. In the repository root (next to your report folders) create a file named _headers (no extension).
    3. Put these two lines in it:
      /*
        Basic-Auth: username:password
    4. Replace username and password with your own (do not use important real passwords — Netlify stores them in the repository config).
    5. Finish the deploy (Netlify picks up the file automatically on the next push) — the browser will now ask for a username and password when someone opens the site.

    More detail: official Netlify docs. A custom login page (instead of the default browser prompt) is only available on Netlify’s paid Pro plan.

Internal “all networks” page (for you / a manager)

You can create a file with a random name (e.g. admin-3e561cef51.html) in the repository root, listing every folder. Because the name is hard to guess and is not linked anywhere, only people you send it to will have it. Do not give this to partners.

FAQ

How much does it cost? — Free (GitHub Pages on a public repository).

How long after upload? — Usually 1–2 minutes while the site builds.

The file does not open (404)? — Check that: (1) Pages is enabled; (2) the path and file name are exact (including upper/lower case); (3) a few minutes have passed.
