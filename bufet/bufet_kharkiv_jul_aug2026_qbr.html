Пояснення всіх метрик звіту
GMV до знижокЗагальна сума замовлень за цінами меню, без вирахування знижок (order_gmv).
AOVAverage Order Value — середній чек = GMV до знижок / кількість замовлень.
Нові клієнтиУнікальні користувачі, для яких дане замовлення — перше в цьому закладі (first_order_created_same_provider_ts).
ЧастотаЗамовлень на одного активного клієнта за період.
Bolt+ часткаЧастка доставок, оформлених підписниками Bolt+.
Провайдер/courier acceptanceЧастка замовлень, прийнятих закладом/курʼєром без відмови (зважено по обсягу тижня).
Session-funnelImpressions → перегляд меню → додано в кошик → замовлення, на основі сесій користувачів у застосунку.
Промо-замовленняЗамовлення зі знижкою по товару або campaign_discount > 0.
